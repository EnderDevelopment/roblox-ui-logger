# Roblox UI Logger

This project provides a developer UI for Roblox Studio that includes a close and reopen button, multiple tabs, and a remote event logger. The UI is designed to be clean and intuitive, making it easier for developers to monitor and debug their games.

## Install

1. Open Roblox Studio and create a new place or open an existing one.
2. Create a `ReplicatedStorage` folder if it doesn't exist.
3. Create a `StarterPlayerScripts` folder if it doesn't exist.
4. Place `DeveloperUI.module.lua` in the `ReplicatedStorage` folder.
5. Place `InitializeUI.client.lua` in the `StarterPlayerScripts` folder.

## Use

1. Run the game in Roblox Studio.
2. The developer UI will appear on the player's screen.
3. Use the tabs to navigate between different sections of the UI.
4. The "Remote Events" tab will display a log of all remote events that are triggered in the game.
5. To close the UI, click the "X" button in the top-right corner of the UI frame.
6. To reopen the UI, click the "Reopen UI" button that appears in the bottom center of the screen.
